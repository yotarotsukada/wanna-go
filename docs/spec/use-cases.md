# 提供ユースケース

wanna-go が現在提供している機能を、ユーザー視点のユースケース単位で列挙する。実装と一対一対応する仕様の主要参照点として置く。

## 1. グループの作成・共有
- アカウント登録なしで新規グループを作成できる。
- 発行されたグループ ID または URL を通じて、家族や恋人とグループを共有できる。
- グループ ID を知っている人全員が、そのグループ配下の編集権を持つ前提（権限分離は行わない）。

## 2. 行きたい場所（ブックマーク）の追加・管理
- URL を入力して、新しい行きたい場所を登録できる。
- カテゴリ、興味度（優先度）、メモなどの付加情報を設定できる。
- 登録済みの場所の情報を編集・削除できる。

## 3. URL メタデータの自動取得
- URL から Web サイトのタイトル、説明文、画像 URL、サイト名などのメタデータを自動取得する。
- 外部 API を活用し、位置情報（緯度・経度）や施設名（Place）も取得・管理できる。

## 4. 訪問ステータスの管理
- 実際に行った場所に対して「訪問済み（`visited`）」マークを付けられる。
- 訪問日（`visitedAt`）を記録する。

## 5. 一覧表示・検索・フィルタリング
- グループ配下のブックマークを一覧で確認できる。
- カテゴリ・訪問状況（未訪問 / 訪問済み）で絞り込みができる。

## 6. テーマ（タグ）管理
- グループ内でテーマを作成し、ブックマークを多対多で束ねて分類できる。

## 7. 統計情報の確認
- グループの活動状況（登録数や訪問数など）を可視化して確認できる。

## カテゴリ
ブックマークが必ず 1 つ持つ固定列挙。実体は `app/lib/constants.ts` の `CATEGORIES`。

- レストラン
- 観光地
- ショッピング
- アクティビティ
- その他
