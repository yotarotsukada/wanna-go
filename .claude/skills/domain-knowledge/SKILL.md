# wanna-go ドメイン知識

## 中核概念

| 用語 | 説明 |
|------|------|
| グループ (Group) | アカウントの代わりとなる共有単位。8 文字英数字 ID で URL 共有する。 |
| ブックマーク (Bookmark) | 「行きたい場所」。1 グループに複数。URL・カテゴリ・興味度・訪問状態を持つ。 |
| テーマ (Theme) | グループ内で任意に作るタグ。ブックマークと多対多で関連付く。 |
| カテゴリ (Category) | ブックマークが必ず 1 つ持つ固定列挙。`app/lib/constants.ts` の `CATEGORIES` を Single Source とする。 |
| URL メタデータ | 登録 URL から自動取得するタイトル・説明・OG 画像・サイト名。Cheerio によるスクレイピング。 |
| 訪問状態 | ブックマーク単位で `visited` / `visitedAt` を持つ。 |

## グループ ID 仕様
- 長さ: 8 文字
- 文字種: 英数字（`0-9`, `a-z`）
- 例: `xy7k9m2p`
- アカウント概念は無く、ID を知っている人全員がそのグループの編集権を持つ前提。

## エンティティ関連（概念図）

```
Group 1 ─── * Bookmark * ─── * Theme
                              （BookmarkTheme で多対多）
Group 1 ─── * Theme
```

- スキーマの確定形は `prisma/schema.prisma` を参照（コピーは置かない）。
- データモデルの設計意図は `docs/spec/data-model.md` を参照。

## 提供ユースケース
詳細は `docs/spec/use-cases.md` を参照。要約のみ:
1. グループ作成・URL 共有
2. ブックマーク（行きたい場所）の追加・編集・削除
3. URL メタデータ自動取得
4. 訪問ステータスの管理
5. カテゴリ / 訪問状況によるフィルタ
6. テーマによる細分類
7. 統計情報の表示
